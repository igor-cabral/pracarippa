PRAÇA RIPPA — V4 MULTIPÁGINA

Abra index.html no navegador para apresentar o site.

Páginas:
- index.html — início
- sobre.html — sobre nós
- localizacao.html — localização

Estrutura:
- assets/css/style.css — estilo compartilhado
- assets/js/main.js — menu, animações e status de horário
- assets/images/ — fotos editáveis

STATUS NO CABEÇALHO:
O site calcula automaticamente o status usando a data e hora LOCAL do navegador do visitante.
Quarta a sábado: 17h–23h. Domingo: 12h–22h. Segunda e terça: fechado.

FOTOS:
As fotos atuais foram extraídas do HTML anterior para facilitar a troca.
Substitua os arquivos em assets/images mantendo os nomes. Para maior qualidade, use fotos
originais em alta resolução e, idealmente, gere versões WebP/AVIF depois.

SEO:
O sitemap e robots.txt ainda usam SEU-DOMINIO-AQUI. Troque pelo domínio definitivo antes
de publicar.
